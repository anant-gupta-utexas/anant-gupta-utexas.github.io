The Work

What I've built professionally.

Most of my recent work has been on the systems around production AI: evaluation, retrieval, orchestration, developer infrastructure, and the workflows that connect models to real decisions.

Production evaluation infrastructure for generative AI

Built and owned evaluation infrastructure for production LLM applications, supporting both online and offline workflows across multiple teams.

The platform made evaluation part of the delivery process rather than a separate manual step, helping teams catch issues earlier, ship changes faster, and bring new data sources into the system with less custom work.

evaluationdistributed systemsLLM-as-judgeKafkaCI/CD

Root-cause analysis and signal detection

Built a system for detecting anomalous business signals and generating structured analysis around them.

The work has since expanded into a broader root-cause-analysis framework that connects signal detection, causal attribution, and recommended actions, while keeping the workflow traceable and allowing people to remain involved where judgment is required.

anomaly detectioncausal attributionagent orchestrationhuman-in-the-loop

Natural-language analytics

Built a natural-language interface that lets business users ask questions in plain language and translates them into structured queries against a governed semantic layer.

The goal was to make analytical access more self-service without bypassing the definitions, business logic, and governance behind the underlying data. The system is now used by a large internal user base for recurring analytical questions that previously required more direct support from data and engineering teams.

natural-language analyticssemantic layersself-service analyticsLLMs

Shared framework for production LLM applications

Designed a common framework for teams building LLM applications, covering agent orchestration, standardized interfaces, deployment workflows, and observability.

The framework was adopted across multiple engineering teams and replaced several pieces of duplicated infrastructure with a shared foundation that teams could extend for their own applications.

framework designagent orchestrationdeveloper experienceobservability

Thinking

How I keep up.

The field moves faster than I can follow by simply reading more.

Instead, I maintain a personal knowledge base built from papers, articles, talks, repositories, and authors I deliberately choose to follow. New material goes through a lightweight pipeline:

curate→distill→connect→build

The useful part isn't collecting information. It's periodically revisiting it, connecting ideas across sources, and turning the ones that matter into something I can use.

How I think about agent systems.

I think of an agent as a system, not just a model with tools. In production, it has to manage context, execution, state, permissions, evaluation, and failure around the model itself.

This is the working model I use to reason about that system.

The agent stack — working model ● Where my work concentrates

Interfaces

Where work enters the system — applications, APIs, messaging surfaces, IDEs, and other entry points.

Orchestration & runtime

Routing, session state, workflow execution, retries, checkpoints, and coordination across tasks and agents.

Models, context & memory

Model selection and inference, retrieval, working context, persistent memory, and the knowledge available to the system.

Tools & execution

The capabilities an agent can invoke and the environments in which those actions run.

Trust & control

Identity, permissions, policy boundaries, approvals, and the points where human judgment is required.

Evaluation & observability

Tracing what happened, measuring whether it worked, understanding failures, and feeding those results back into the system.

Infrastructure

The compute, storage, queues, databases, and distributed systems supporting the rest of the stack.

My work has been concentrated around orchestration, retrieval and context, evaluation, observability, and the infrastructure connecting these pieces.
